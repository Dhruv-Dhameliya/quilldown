FAQ

Questions, answered.

What is Markdown?

Markdown is a lightweight way to format text using plain characters — # for headings, ** for bold, - for lists. It’s used for documentation, READMEs, notes, blogs and more, and converts cleanly to HTML.

Is Quilldown free? Do I need an account?

It’s free and there is no account. Open the page and start writing.

Where is my text stored?

Only in your browser. Every tab is autosaved to local storage on your device and is never uploaded. Everything the editor needs — libraries and fonts included — is bundled with the site, so it makes no third-party requests. Clearing your browser’s site data will remove saved tabs, so export anything important.

Can I work on several documents at once?

Yes. Each document opens in its own tab — add a blank one with +, open or drop several files at once, drag tabs to reorder, double-click a name to rename, and middle-click to close. Closed a tab by accident? Hit Undo in the message that appears.

Which Markdown flavor is supported?

GitHub-flavored Markdown — tables, task lists, strikethrough, autolinks and fenced code with syntax highlighting — plus KaTeX math ($…$ and $$…$$), Mermaid diagrams, and GitHub-style callouts like > [!NOTE].

Can I paste the result into Google Docs, Word or email?

Yes. Use Copy on the preview pane for rich text that matches the preview, or Copy for Docs for a version with explicit point sizes — H1 23 pt, H2 17 pt, H3 14 pt and body text 12 pt — with no font set, so the text adopts the font of the document you paste into and keeps the heading hierarchy intact in Google Docs and Word.

Which formats can I export to?

PDF (through your browser’s print dialog — choose “Save as PDF”), Word (.docx) that opens in Word, Google Docs and Pages, a PNG image of the whole document, an EPUB e-book for Apple Books, Kobo and other readers, a standalone HTML page, Markdown (.md) and plain text (.txt). In the Word export, equations are included as text (their TeX source) and diagrams as images; very long documents are too tall for a single PNG, so use PDF for those.

Does it work offline? Can I install it?

Yes. All libraries, fonts and icons are bundled with Quilldown, so it never needs a third-party server. When the site is hosted over https, a service worker caches everything on your first visit and an Install button appears (Chrome, Edge and other browsers) so you can run it like a desktop or phone app — with or without a connection. Your documents are stored on your device either way.

Is there a table editor or an emoji picker?

Both. Click the Table button to build a table in a visual grid — or place your cursor inside an existing table (or select spreadsheet rows) and click it to edit or convert. The smiley button opens the emoji picker with search, categories, skin tones and recent picks — or just type : and a few letters for inline suggestions (switch them off in the picker if you prefer).

How does sharing work? Is my document uploaded?

Click Share and Quilldown compresses your document into the link itself. Nothing is uploaded — the part of a link after the # is never sent to a server — so anyone who opens the link gets their own private copy in a new tab. Long documents make long links (there is a warning above ~8,000 characters and a hard stop at 64,000), and pasted images aren’t included. For bigger documents, export to PDF, Word or Markdown.

Are there templates?

Yes — New → Templates offers a README, meeting notes, résumé, blog post, email, tables, to-do list and notes. Each opens in a new tab so your current document is untouched.

Can I add images to a document?

Yes. Paste a screenshot straight into the editor, drop an image file onto it, or use Image → Upload. Quilldown shrinks large images and stores them with that document in your browser; the text shows a short img: reference. Exporting to HTML, PDF or Word includes the picture, and Save .md embeds it in the file. Very large images may exceed your browser’s storage — export before clearing site data.

Does it support footnotes, search and an outline?

Yes — footnotes with [^1] (real footnotes in Word), Find & replace with Ctrl+F / Ctrl+H (case, whole word and regex options), and an Outline sidebar you open from the list icon in the top bar.

Can I open files from my computer?

Yes — click Open (or press Ctrl+O), or drag and drop .md, .markdown or .txt files anywhere on the page; each opens in its own tab. In Chrome and Edge the tab stays linked to the file (a small dot on the tab), so Ctrl+S saves your changes straight back to it — an orange dot means unsaved changes. In other browsers, Ctrl+S downloads a .md instead.

Can I open .md files with Quilldown from my desktop?

Yes, once it is installed as an app (Chrome or Edge, from the Install button on a hosted copy). Quilldown registers for Markdown files, so it appears under Open with when you right-click a .md file; double-clicking a second file opens it as another tab in the same window. If you installed it before this feature existed, uninstall and install it again so your system picks up the change.
