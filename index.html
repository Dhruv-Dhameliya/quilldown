Why Markdown

Write in plain text. Publish anywhere.

Markdown turns a few keystrokes — # for headings, **bold**, - for lists — into a formatted document. The file stays plain text, so it opens anywhere and works with Git. Quilldown handles the last mile: PDF, Word or a web page from the same source. New to it? Read what Markdown is or keep the cheat sheet open.

Getting started

What is Quilldown, and who is it for?

Quilldown is a free online Markdown editor. You type Markdown on one side and a live preview updates on the other, then you copy the result into Google Docs or export it as a PDF, Word file, PNG, EPUB, HTML page or plain text.

It suits anyone who likes to write in plain text but has to hand over a polished document: developers writing READMEs, students taking notes with equations, bloggers drafting posts, and teams writing meeting notes or specs. If Markdown is new to you, start with what Markdown is.

Is Quilldown free? Do I need an account?

Yes, it is free, and there is no account, sign-up or email address to give. Open the page and start writing.

Quilldown is also open source, so you can read exactly what it does on GitHub.

Which browsers and devices does it work on?

Any current version of Chrome, Edge, Firefox or Safari, on desktop, tablet or phone. On phones the editor shows one pane at a time — switch between writing and preview with the view buttons in the top bar. Quilldown opens on the homepage everywhere; turn on Start in editor in the header if you would rather land in the full-screen editor.

A few conveniences depend on the browser: linking a tab to a file on disk (so Ctrl+S saves back to it) works in Chrome and Edge, and the Install button appears in browsers that support installing web apps.

How is this different from writing in Word or Google Docs?

The source is plain text, so your writing is portable, easy to search and safe to keep in Git. Formatting is typed (#, **, -) instead of clicked, which keeps your hands on the keyboard and keeps the structure consistent.

You still end up with a formatted document: Copy for Docs pastes clean headings and lists into Google Docs, and Export → Word (.docx) produces a real Word file. You choose the destination after writing, not before.

Privacy & storage

Where is my text stored? Is it private?

Only in your browser. Every tab is autosaved to your device’s local storage, and nothing you write is uploaded to a server. There is no account, so there is no cloud copy either.

Everything the editor needs — libraries, fonts and icons — ships with the site, so Quilldown makes no third-party requests while you work. You can confirm that in your browser’s network panel.

What happens if I clear my browser data?

Saved tabs are removed with it, and because nothing is stored elsewhere they cannot be recovered. Save important documents as files with Export → Markdown (.md) or Ctrl+S.

Browsers typically allow around 5 MB of local storage per site. Text uses very little of that, but pasted images are stored with the document and count towards the limit, so a document with many large images can hit it first.

Does Quilldown use cookies, trackers or analytics on my writing?

No. Rendering, copying and every export happen locally in your browser, and nothing about what you write is measured or sent anywhere.

The only things Quilldown keeps are your own drafts and a few preferences, such as the theme and your start-page choice, all in your browser’s storage on your device.

Writing & Markdown

Which Markdown flavor does Quilldown support?

GitHub Flavored Markdown (GFM): everything in the original Markdown plus tables, task lists, strikethrough, autolinks and fenced code blocks with syntax highlighting. It is the flavor GitHub, GitLab and most documentation tools use.

On top of GFM you get KaTeX math ($…$ and $$…$$), Mermaid diagrams, footnotes, emoji shortcodes and GitHub-style callouts such as > [!NOTE]. The Markdown cheat sheet shows every piece of syntax with a live example.

Does it support LaTeX math and diagrams?

Yes. Write inline math with $…$ and display math with $$…$$; it renders with KaTeX, including fractions, sums, integrals, matrices and aligned equations.

Flowcharts, sequence diagrams, Gantt charts, class, state and ER diagrams and mind maps are drawn from mermaid code blocks, and they follow the light or dark theme. See math in Markdown and Mermaid diagrams.

Can I make a Markdown table without typing pipes?

Yes. Click Table to build one in a visual grid, set column alignment, and insert it. Put the cursor inside an existing table, or select rows copied from a spreadsheet, and click it again to edit or convert them.

Rows copied from Excel or Google Sheets can be pasted straight in. The Markdown table guide explains the syntax behind it.

Can I add images, footnotes and emoji?
  • Images — paste, drop or upload them. They are stored with the document and included in exports.
  • Footnotes — write [^1] where the note belongs; the Word export turns them into real footnotes.
  • Emoji — type :roc for suggestions or use the emoji picker (shortcode list).
Are there templates and keyboard shortcuts?

Templates for a README, meeting notes, résumé, blog post, email, tables, a to-do list and notes are under New → Templates.

Shortcuts include Ctrl+B bold, Ctrl+I italic, Ctrl+U underline, Ctrl+E inline code, Ctrl+K link, Ctrl+F find, Ctrl+H replace, Ctrl+O open, Ctrl+S save and Esc to leave full screen (⌘ instead of Ctrl on a Mac). Hover any toolbar button to see its shortcut.

Exporting & converting

Which formats can I export to?
  • PDF — through your browser’s print dialog; choose “Save as PDF”.
  • Word (.docx) — opens in Word, Google Docs and Pages.
  • PNG — an image of the whole document.
  • EPUB — an e-book for Apple Books, Kobo and other readers.
  • HTML — a standalone, styled web page.
  • Markdown (.md) and plain text (.txt).

Very long documents are too tall for a single PNG, so use PDF for those.

How do I convert Markdown to PDF?

Write or paste your Markdown, choose Export → PDF, and pick “Save as PDF” as the destination in the print dialog. It is free, private and works offline.

If code blocks or tables look flat, turn on “Background graphics” in the print options. The Markdown to PDF guide covers page breaks and print settings in detail.

How do I convert Markdown to Word or Google Docs?

Two routes. Export → Word (.docx) gives you a real Word document. Copy for Docs (on the preview pane) puts formatted text on your clipboard, ready to paste into Google Docs.

Copy for Docs uses point sizes Docs understands — H1 23 pt, H2 17 pt, H3 14 pt, body 12 pt — and sets no font, so the text takes on your document’s font. More in Markdown to Word and Google Docs.

Can I convert Markdown to HTML?

Yes. Copy → HTML puts clean markup on your clipboard for a website or CMS, and Export → HTML saves a standalone, styled web page. Markdown to HTML shows what the generated markup looks like.

Why do equations and diagrams look different in Word?

Word has no KaTeX or Mermaid renderer, so the .docx keeps equations as their TeX source text and inserts diagrams as images. If equations need to look typeset, export to PDF instead, where they render exactly as in the preview.

Files, tabs & offline

Can I work on several documents at once?

Yes. Each document opens in its own tab. Add a blank one with +, open or drop several files at once, drag tabs to reorder them, double-click a name to rename it and middle-click to close.

Closed a tab by accident? Press Undo in the message that appears.

Can I open and save .md files from my computer?

Yes — click Open (Ctrl+O) or drag and drop .md, .markdown or .txt files anywhere on the page. Each opens in its own tab.

In Chrome and Edge the tab stays linked to the file (a small dot on the tab), so Ctrl+S saves straight back to it and an orange dot means unsaved changes. Elsewhere, Ctrl+S downloads a .md file. Once installed as an app, Quilldown also appears in your system’s “Open with” menu for Markdown files.

Does it work offline? Can I install it?

Yes. Everything ships with the site, and after the first visit a service worker caches it, so Quilldown loads and exports without a connection. An Install button appears in Chrome, Edge and other browsers that support it, letting you run Quilldown like a desktop or phone app.

Sharing & support

How does sharing work? Is my document uploaded?

Click Share and Quilldown compresses your document into the link itself. Nothing is uploaded: the part of a link after the # is never sent to a server, so anyone who opens it gets their own private copy in a new tab.

Long documents make long links — there is a warning above about 8,000 characters and a hard stop at 64,000 — and pasted images are not included in shared links.

How do I report a bug or contact the maintainer?

Open an issue on GitHub with your browser and, if possible, a small sample of the Markdown involved. The code is public at Dhruv-Dhameliya/quilldown.

For press or general enquiries, use the maintainer’s GitHub profile; the About & press page has a logo and boilerplate.
