About Quilldown

Quilldown is a free, private Markdown editor that runs entirely in your browser. This page explains what it is, how it is built, and how to reach the person behind it.

What Quilldown is#

Quilldown is a Markdown editor for people who like to write in plain text but need a polished result. You type Markdown on one side, and the formatted document appears on the other as you go. When you are finished you can copy it into Google Docs, or export it as a PDF, a Word document, a PNG image, an EPUB e-book, an HTML page or plain text.

It is a single web page, not an account-based service. There is nothing to sign up for, nothing to install, and no server that receives your writing.

Why it exists#

Most Markdown tools fall into one of two groups: heavyweight note-taking apps that want you to live inside them, or bare-bones previewers that stop at showing you the result. Quilldown aims for the space between. It should open instantly, stay out of the way, and make the last step — getting the text into Word, Google Docs, a PDF or a website — genuinely painless.

Three principles shape every decision:

  • Private by default. Your text is stored only in your browser. Libraries, fonts and icons are bundled with the site, so the editor makes no third-party requests while you write.
  • Calm and fast. A quiet interface, a live preview that keeps up with your typing, and synced scrolling so you never lose your place.
  • Useful output. Copy for Google Docs uses real point sizes (H1 23 pt, H2 17 pt, H3 14 pt, body 12 pt) and sets no font, so the text takes on the font of the document you paste it into.

Contact and media enquiries#

Quilldown is built and maintained by Dhruv-Dhameliya. The best way to get in touch is through GitHub:

  • Media, press and general enquiries — visit the maintainer’s GitHub profile and follow the contact links there.
  • Bug reports and feature requests — open an issue on the Quilldown repository. Include your browser and a short description or a sample of the Markdown that triggered the problem.
  • Source code — browse or fork the Quilldown repository.

Note

Quilldown has no server and no user accounts, so there is no way for anyone — including the maintainer — to see or recover the documents you write. If you report a bug, share only text you are comfortable making public.

Frequently asked questions#

Is Quilldown really free?

Yes. There is no paid tier, no account and no advertising. The source code is public on GitHub.

Does Quilldown collect or store my documents?

No. Your text is autosaved in your own browser’s storage and is never sent to a server. Clearing your browser’s site data removes saved tabs, so export anything important.

How do I report a bug or request a feature?

Open an issue on the Quilldown GitHub repository. A clear description and, if possible, a short sample of the Markdown involved makes problems much faster to reproduce.

How can I contact the maintainer for press or partnership questions?

Use the maintainer’s GitHub profile. It is the official contact point for Quilldown.
