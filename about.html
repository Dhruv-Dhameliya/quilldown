What Quilldown is

Quilldown is a Markdown editor for people who like to write in plain text but need a polished result. You type Markdown on one side and the formatted document appears on the other as you go. It supports GitHub Flavored Markdown, LaTeX math and Mermaid diagrams. When you're finished, you can copy the result or export it as a PDF, a Word document, a PNG image, an EPUB e-book, an HTML page, Markdown or plain text.

It's a single web page. There's nothing to sign up for, nothing to install, and no server that receives your writing.

Why it exists

Most Markdown tools fall into one of two groups: heavyweight note-taking apps that want you to live inside them, or bare-bones previewers that stop at showing you the result. Quilldown aims for the space between. It should open instantly, stay out of your way, and make the last step painless, whether that means a PDF for submission, a Word file for a colleague, a web page for a blog, or a paste into another app.

I built it because every Markdown editor I tried felt the same: generic, short on features, and unable to copy the formatted text the way it looks in the preview. So I made the one I wanted. You're welcome.1

Five ideas behind every decision

  • Private by default. What you write isn't sent anywhere, and there's no account to tie it to. Drafts are saved in your own browser, and every library and font is bundled with the site, so the editor makes no third-party requests while you write. Read more
  • Calm and fast. A quiet interface and a live preview that keeps up with your typing. Scrolling is synced block by block, so you never lose your place. Read more
  • Useful output. What matters is what comes out the other end. Quilldown exports to seven formats and offers several ways to copy, including a version made for Google Docs with real heading sizes (H1 at 23 pt, H2 at 17 pt, H3 at 14 pt, body at 12 pt) that sets no font, so your text takes on the font of the document you paste it into. Read more
  • Honest about limits. There's no real-time collaboration and no cloud sync, and drafts live only in your browser. This site says so plainly instead of hiding it. Read more
  • Open to inspection. Quilldown is written in plain HTML, CSS and JavaScript with no build step, and the code is public on GitHub under the MIT License. You can read exactly how it works. Read more

What Quilldown isn't

Good to know

Knowing what a tool doesn't do saves you time, so here are the main things.

  • It isn't a collaboration tool. There's no real-time co-editing or comments. You can share a link to a copy of a document, and that's all.
  • It isn't cloud storage. Drafts live in your browser, so clearing your browser data deletes them. Export anything important as a .md file.
  • It doesn't sync between devices. Move documents with exported files or shared links.
  • It isn't a full word processor. In Word exports, equations stay as TeX source and diagrams become images.
  • It has practical limits: files up to 5 MB each, up to 30 tabs open at once, and browser storage of roughly 5 MB in total, so very large images may not be kept between visits.

If your work needs something on this list, another tool may suit you better. If Quilldown fits what you do, we hope it stays out of your way.

Built on other people's open-source work

Quilldown's own code is released under the MIT License, which means you're free to use, copy, modify and share it, as long as you keep the copyright notice.

It also stands on the shoulders of other open-source projects, all bundled with the site so nothing loads from a third-party server. Each of these keeps its own license.

Contact and feedback

The best way to reach the maintainer is through GitHub.

  • Bug reports and feature requests. Open an issue on the Quilldown repository. Include your browser and, if you can, a small sample of the Markdown involved.
  • General, partnership and media enquiries. Visit the maintainer's GitHub profile and follow the contact links there.
  • Source code. Browse or fork the Quilldown repository.

Note

Quilldown has no server and no user accounts, so there is no way for anyone, including the maintainer, to see or recover the documents you write. If you report a bug, share only text you're comfortable making public.

Frequently asked questions

Is Quilldown really free?

Yes. There's no account, no sign-up and no email address to give. And no ads.

Does Quilldown collect or store my documents?

No. What you write stays in your browser, and drafts are autosaved to your own device only. Nothing is uploaded, there's no server copy, and there's no analytics. The privacy page lists exactly what is stored.

Is Quilldown open source?

Yes. The code is public on GitHub under the MIT License, so you can read it, use it, change it and share it.

Who makes Quilldown?

See the Who makes it section above.

How do I report a bug or suggest a feature?

Open an issue on GitHub with your browser and, if possible, a small sample of the Markdown involved.

How can I contact the maintainer for press or partnership questions?

Use the contact links on the maintainer's GitHub profile.
